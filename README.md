# Codex Desktop Proxy Troubleshooting

一份针对 macOS Codex Desktop 代理、DNS 污染和 WebSocket 连接问题的排查指南。

适用现象：

- `Selected model is at capacity. Please try a different model.`
- `tls handshake eof`
- `WebSocket was closed before the connection was established`
- 对话卡住、重试或无法建立连接

完整路径见 [CODEX-DESKTOP-PROXY-TROUBLESHOOTING.md](CODEX-DESKTOP-PROXY-TROUBLESHOOTING.md)。
